PHENOIMAGE E22 - CORRECCION DEL INSTALADOR DE EJEMPLOS

Causa: ambos ejemplos originales contienen un archivo auxiliar .cpg de cero bytes. E21 rechazaba cualquier archivo vacío.
Corrección: solo .cpg puede tener cero bytes; imágenes y componentes principales requieren tamaño positivo. Se conservan la verificación de rutas, lista de archivos, tamaño extraído, no sobrescritura implícita y reemplazo controlado. No se inventa la codificación ni se modifican archivos de entrada.

Entorno: R 4.5.0/Linux.
PASS: instalación real de phenoImage 4.7.0.22 en biblioteca nueva.
PASS: reproducido el error E21 con el ZIP RGB real y su .cpg de cero bytes.
Ejemplo rgb instalado. Puedes elegir 'Usar ejemplo' en PhenoImage.
Ejemplo sentera instalado. Puedes elegir 'Usar ejemplo' en PhenoImage.
PASS: ambos ZIP reales instalados; imágenes y shapefiles idénticos por MD5; .cpg vacíos conservados.
PASS: imagen principal vacía rechazada; datos instalados intactos.

Los ZIP de prueba se construyeron a partir de todos los archivos originales, sin sustituir las imágenes por datos simulados. Se compararon los archivos extraídos con sus originales mediante MD5. La prueba negativa sí usa archivos pequeños simulados para comprobar que una imagen principal vacía sigue siendo rechazada.
No se ejecutó el análisis completo del usuario en Windows. No cambiaron las fórmulas ni las funciones principales de procesamiento.
